## What AccessLens Does

AccessLens is a web application that brings an accessibility-focused review step into the UI design process. Its AI-assisted analysis helps identify possible accessibility problems in interface concepts while changes are still relatively easy to make, before development begins.

The tool is designed for design, product, and engineering groups assessing interface choices against WCAG 2.1 AA expectations. Since AccessLens operates in a browser and follows HTML-oriented workflows, it can be used during design critiques and front-end planning without requiring a desktop installation.

## Getting Started

AccessLens is browser-based, so installation consists primarily of obtaining the project and serving it through a web environment.

1. Clone or download the repository:
   `git clone https://github.com/brandonfchughes1754/accesslens-ui-audit-tool.git
2. Change into the project directory:
   `cd accesslens-2026-a11y-tool`
3. Serve the files with a local preview tool or your preferred web server.
4. Open the resulting address in a browser to start reviewing designs.

For static previews, serve the HTML through a local or hosted web server instead of opening the files directly from the filesystem.

## Using AccessLens

The basic review process is:

1. Start AccessLens in a browser.
2. Load or reference the interface design to be assessed.
3. Begin an accessibility review.
4. Examine the reported findings alongside WCAG 2.1 AA expectations.
5. Revise the design before proceeding to implementation.

To create a simple local preview, run:

`python -m http.server`

After the command starts, open the local URL displayed in the terminal and use the application there.
